SPRINT69 설치 방법

1. 이 ZIP 파일을 다운로드합니다.
2. ZIP을 엽니다.
3. 안의 social 폴더 전체를 복사합니다.
4. 아래 프로젝트 폴더 안에 붙여넣습니다.

C:\Users\user\Downloads\AutoCommerceAI_4.0_PlaywrightSourceCollector-0630\modules

최종 경로:
...\modules\social\__init__.py

5. 프로젝트 PowerShell에서 실행:
python -m compileall modules/social

6. 버전 확인:
python -c "from modules.social import ChromeProfileManager, TikTokSessionManager, CaptchaDetector, SocialCommentCollector; print(ChromeProfileManager.VERSION); print(TikTokSessionManager.VERSION); print(CaptchaDetector.VERSION); print(SocialCommentCollector.COLLECTOR_VERSION)"
